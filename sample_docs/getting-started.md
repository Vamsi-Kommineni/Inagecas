# Getting started with Acme Cloud

## Creating an account

Sign up at https://app.acme.example with a work email address. After you confirm
the verification email, your account is created on the Free plan with a single
workspace.

## Inviting teammates

Workspace owners can invite teammates from **Settings → Members → Invite**.
Invited users receive an email link that is valid for 7 days. The Free plan
allows up to 3 members per workspace; larger teams require the Team plan.

## Creating your first project

From the dashboard, click **New project**, give it a name, and choose a region.
The region cannot be changed after a project is created, so pick the one closest
to your users.

## API keys

Generate an API key from **Settings → API keys**. Keys are shown only once at
creation time. Treat keys as secrets and rotate them if they are exposed.
